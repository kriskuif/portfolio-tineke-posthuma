# Portfolio Tineke Posthuma

Digitale portfolio-website voor **Wandeltrainer 3**.

De website is bewust gestart als een rustige basisopzet. Persoonlijke teksten, praktijkvoorbeelden, trainingsplannen, reflecties en bewijsstukken worden later toegevoegd.

## Publiceren met GitHub Pages

De website bestaat uit statische HTML en kan rechtstreeks via GitHub Pages worden gepubliceerd vanuit de `main` branch en de map `/ (root)`.
